# Прямой прокси

Felucca может предоставить точку входа SOCKS5 или HTTP из-за NAT. На этой странице описаны три
режима, аутентификация по учётным записям, ACL целей и поведение UDP.

## Три режима

```toml
[[tunnel]]
mode = "socks5"
port = 9080
bind = "127.0.0.1"
acl_mode = "allow"
acl_rules = "127.0.0.0/8, ::1/128"

[[tunnel]]
mode = "httpproxy"
port = 9081
bind = "127.0.0.1"

[[tunnel]]
mode = "mixedproxy"
port = 9082
bind = "127.0.0.1"
```

| `mode` | Поддержка |
| --- | --- |
| `socks5` | CONNECT + UDP ASSOCIATE; IPv4/IPv6; разрешение имён на стороне агента; BIND возвращает "unsupported command" |
| `httpproxy` | Запросы с абсолютным URL + CONNECT |
| `mixedproxy` | Различает SOCKS5 и HTTP по началу запроса |

Примеры прямого прокси привязаны только к `127.0.0.1`. Когда вам нужен удалённый доступ, **также**
задайте список разрешённых источников; иначе любой, кто может дотянуться до этого порта, сможет
пользоваться вашим исходящим трафиком.

## Аутентификация по учётным записям

Добавьте таблицу учётных записей в текущий туннель, чтобы включить аутентификацию:

```toml
[tunnel.options.auth.users]
alice = "replace-with-a-password"
bob = "another-password"
```

| Запись | Аутентификация | Ответ при ошибке |
| --- | --- | --- |
| SOCKS5 | Метод имени пользователя и пароля, **без понижения** до анонимного доступа | Ошибка аутентификации |
| HTTP прямой прокси / CONNECT | `Proxy-Authorization: Basic` | 407 |
| Сайт обратного прокси HTTP | `Authorization: Basic` | 401 |

Без таблицы учётных записей разрешён анонимный доступ. Проверенные учётные данные прокси и сайта
удаляются до отправки запроса на бэкенд. Конфигурация и регистрационные сообщения содержат пароли
учётных записей, поэтому мост должен использовать TLS, WSS или QUIC по умолчанию; `tcp` и `ws` —
это явно выбранные транспорты открытого текста.

Файловые туннели используют `tunnel.file.auth`, который нельзя применять вместе с
`tunnel.options.auth`.

## Политика целей

Туннели с фиксированным бэкендом используют `target_policy`, чтобы ограничить фактическую цель.
Прямойому прокси она нужна в особенности:

```toml
[tunnel.target_policy]
allow = ["domain:api.example.com", "suffix:example.net", 'regex:^db[0-9]+\.internal$']
deny = ["127.0.0.0/8", "::1", "169.254.0.0/16"]
ports = [80, 443]
```

Пустой список `allow` не ограничивает допустимые цели, `deny` всегда имеет приоритет, а пустой
список `ports` разрешает любой ненулевой порт. Поддерживаются правила IP/CIDR, `domain:` для
точного доменного имени, `suffix:` для суффикса (включая корневой домен и поддомены любой
глубины), `regex:` для регулярного выражения, а `*` — для соответствия всем целям. Имена
нечувствительны к регистру, а конечная точка нормализуется.

Сначала выполняется разрешение DNS, затем **первоначальное имя и фактический IP-адрес**
проверяются по очереди. Соединение использует только прошедшие проверку адреса и не
разрешается повторно, поэтому разрешённый домен не может обойти запрещённый IP-адрес. GeoIP и
GeoSite также поддерживаются; см. [Управление доступом, квоты и кодирование потока](security.md).

## UDP ASSOCIATE в SOCKS5

- Принимается только IP-адрес собеседника управляющего соединения: когда в запросе указан порт,
  он фиксируется, а иначе привязывается порт источника первого корректного UDP-пакета.
- Закрытие управляющего TCP-соединения очищает все ассоциации целей.
- Каждый сеанс допускает не более 64 целей, каждая из которых ставит в очередь 8 пакетов, а
  неактивные записи освобождаются через 60 секунд.
- Ненулевое значение FRAG отбрасывается, а сборка фрагментов SOCKS5 не реализована.

## Ограничение скорости и квота

- Поле `tunnel.options.limits.rate_limit` задаёт предел в байтах в секунду, общий для всех
  туннелей агента и для обоих направлений, и допускает начальный всплеск в одну секунду трафика.
- Поле `quota.flow_limit` учитывает оба направления, а `quota.expires_at` использует секунды
  Unix.
- Квоты проверяются периодически и разрывают соединения, которые уже передают данные, поэтому
  параллельный трафик в полёте может превысить квоту. Эти счётчики не предназначены для строгого
  биллинга.
